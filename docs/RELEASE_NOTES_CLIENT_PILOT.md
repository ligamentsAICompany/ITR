# Release Notes: Client Pilot Launch Pack

Product: Liga AI Tax Platform
Version: Phase 13 Client Demo / Pilot Launch Pack
Date: 2026-05-30

## Features

- Client demo script and product walkthrough.
- Synthetic demo personas and document samples.
- Safe demo-data summary utility.
- Taxpayer, reviewer/admin, scope, risk, metrics, and smoke checklist docs.
- Frontend pilot-mode status banner.

## Supported Scenarios

- ITR-1 salaried resident demo.
- ITR-2 capital gains or foreign asset review demo.
- ITR-3 business/proprietor classification demo.
- ITR-4 presumptive income demo.
- Mock/sandbox filing readiness diagnostics.

## Known Limitations

- Live government filing is disabled.
- No live ERI, e-verification, payment, or acknowledgement workflow is enabled.
- Sandbox verification requires approved provider specs and credentials.
- OCR/scanned PDF handling is limited and should not be relied on for pilot
  acceptance without separate validation.

## Security And Privacy

All bundled data is synthetic. Do not use actual taxpayer data in the client demo.
No credentials or secrets are included in the launch pack.

## Next Improvements

- Approved sandbox provider onboarding.
- Stronger audit trail exports.
- Expanded document parsing after client pilot feedback.
- Enterprise deployment hardening.
