# Pilot Success Metrics

## Workflow Completion

- 90% of synthetic demo workflows complete from profile to package preview.
- 100% of demos show live filing disabled.
- 100% of demo runs use only synthetic or approved pilot data.

## Quality

- ITR recommendation visible for each supported demo persona.
- Validation report generated for each completed demo workflow.
- Tax computation summary generated after approved values are available.
- Reviewer can identify blockers and warnings without engineering help.

## Readiness

- Mock filing readiness visible for demo workflows.
- Sandbox diagnostics clearly distinguish verified and `NOT_VERIFIED` items.
- No secrets, raw credentials, or actual taxpayer data appear in logs or docs.

## Client Acceptance

- Client can explain what is supported and unsupported after the walkthrough.
- Client identifies whether to proceed to controlled sandbox onboarding.
- Non-blocking pilot issues are captured with owner and status.
