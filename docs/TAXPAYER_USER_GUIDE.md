# Taxpayer User Guide

## What This Platform Does

This pilot helps prepare and validate tax filing data. Live government filing is
disabled.

## Profile

Enter only demo or approved pilot information. For client demos, use the fake
personas in `demo_data/`.

## Uploads

Upload supported sample documents such as Form 16-like CSV, AIS-like CSV, Form
26AS-like CSV, or capital gains samples. Do not upload actual taxpayer documents
for the demo.

## Extracted Values

The system may suggest extracted values. Review them carefully. Only approved
values are used in the workflow.

## Recommendation And Validation

The platform recommends an ITR type and shows validation issues. Fix missing or
conflicting values before continuing.

## Tax Computation

The tax panel shows a computation summary from approved values. Treat it as pilot
workflow output that still needs reviewer approval.

## Filing Package And Export

The filing package and schema export are draft pilot artifacts. They are not live
government submissions.

## Consent And Mock Filing

Consent and mock/sandbox filing readiness screens demonstrate the workflow only.
They do not perform live filing, live e-verification, payment, or acknowledgement
retrieval.
