Synthetic demo schema packs for the local and deployed demo workflow.

These files are JSON Schema 2020-12 test schemas used only to validate the demo export payload shape generated by this repository. They are not official government schemas, do not represent Income Tax Department schema requirements, and must not be described as government-approved filing schemas.

Load them with:

```bash
python -m app.tools.load_demo_schema_packs
```

The loader registers and activates one synthetic test pack per ITR form for AY 2026-27:

- ITR-1 AY 2026-27
- ITR-2 AY 2026-27
- ITR-3 AY 2026-27
- ITR-4 AY 2026-27

The validation intent is deliberately narrow: prove that the candidate ITR plus assessment year resolves an active schema pack, the deterministic mapper can produce required export fields, and artifacts are generated only after JSON Schema validation passes. Live filing remains disabled by configuration and these packs do not call any government or ERI endpoint.
